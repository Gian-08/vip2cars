Pasos para correr sistema laravel CRUD VIP2CARS

- XAMPP v3.2.2
- Composer 

1. Clonar repositorio
2. Ejecutar composer install
3. Crear base de datos 'db_vipcars' en phpMyAdmin o importarlo se encuentra el la carpeta bd es un archivo .sql
4. Ejecutar php artisan migrate en la terminal
5. Luego para correr el proyecto ejecutar en la terminal php artisan serve
